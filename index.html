AUTO-HOSPEDAGEM • DOCKER

Hospede no seu próprio computador

Prefere rodar tudo na sua máquina ou rede local? O projeto já inclui Dockerfile e docker-compose.yml prontos para subir o Canivete Digital em segundos.

🐳 Docker & Docker Compose 🗄️ Banco SQLite integrado ◈ Porta padrão: 8080 ⚡ Node.js 24 + Sharp inclusos
Opção 1 • Recomendado

Subir com Docker Compose

Baixe o repositório e inicie o container com banco SQLite pronto em volume local (/app/.data/canivete.db) e sem configuração externa.

terminal — docker compose 
git clone https://github.com/Kyouz2148/dockercanivetedigital.git
cd dockercanivetedigital
docker compose up -d --build
Opção 2 • Docker CLI

Construir e executar diretamente

Se preferir usar apenas o comando docker, construa a imagem e monte um volume para manter imagens e links salvos no SQLite.

terminal — docker build & run 
docker build -t canivete-digital .
docker run -d -p 8080:8080 -v canivete_data:/app/.data --name canivete canivete-digital
Acesso local com SQLite pronto: após subir o container, abra http://localhost:8080 no navegador. Tanto a Hospedagem de imagens (com exclusão automática em até 7 dias) quanto os links locais usam SQLite em /app/.data/canivete.db — sem precisar instalar PostgreSQL.
